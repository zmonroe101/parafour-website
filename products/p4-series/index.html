The P4 Dispenser Computer

At the heart of every P4 Series dispenser is the P4 dispenser computer — the certified electronic register that measures, computes, and records every transaction. Running software version 4.45C, the P4 Series is NTEP Category 1 certified — the highest weights-and-measures designation available in the United States — meaning no mechanical seal is required and all calibration and configuration changes are tracked electronically in an event log accessible to any W&M inspector.

Engineered for fleet, autogas, and commercial fueling environments, the P4 Series is compatible with Neptune/Liqua-Tech and Liquid-Controls MA4 series meters as well as mass flow meters, and supports both single and dual hose configurations. Automatic Temperature Compensation (ATC) is built in per API Standard 2450 / ASTM D 1250 / ISO R91, correcting volume delivery to 60°F reference temperature for accurate, legally defensible transactions.

The P4 Series is MET listed and carries CE and GOST certifications for international markets, and meets NEC Class 1, Division I and II hazardous area requirements for installation at LPG fueling facilities.

Key Features

Engineered for the demands of commercial LPG dispensing — from transaction accuracy to W&M compliance.

🌡

Automatic Temperature Compensation

Built-in ATC corrects LPG volume to the 60°F reference standard per API 2450, ASTM D 1250, and ISO R91 — ensuring accurate, temperature-adjusted delivery for every transaction.

💲

Multi-Pricing

Up to 5 configurable price levels selectable via keypad or nozzle switch. Supports fleet pricing, retail pricing, and bulk discount tiers without hardware changes.

🎯

Preset Dispensing

Amount or volume preset entry via keypad or external preset button. Supports single and dual solenoid valve configurations for precise delivery cutoff.

📋

Sales History

Stores up to 8,000 transaction records with timestamp, volume, price, and delivery data. Retrieving full history and reports requires optional field management software or an optional receipt printer connected via serial port.

📊

Shift Reporting

Attendant login/logoff with shift-level totalizers — requires the optional security/shift controls package. Printed shift reports require field management software or the optional receipt printer.

🔌

Smart Meter & System Integration

Gilbarco protocol over RS232, RS485, or 2-wire current loop (4800 / 5787 / 9600 baud). Compatible with Liqua-Tech 250 pulsers, mass flow meters, and industry-standard fuel management and back-office systems.

💳

Card Reader Integration

MCR authorize signal input with programmable pulse output (1, 10, or 100 pulses per unit volume) and configurable pulse width (0.5–30ms) for compatibility with a wide range of card reader and fleet card systems.

✓

NTEP Category 1 Compliant

The highest W&M designation available. Calibration and configuration event logs are maintained electronically and are accessible to any weights-and-measures inspector — no mechanical seal required.

Menu System

The P4 Series uses a 6-level password-protected menu hierarchy. Each level controls a discrete set of functions, keeping daily operations separate from calibration and W&M-controlled parameters. Full menu documentation is available in the P4 Series Manual.

Attendant

Daily pump operations — transaction entry, price selection, preset input, and start/stop controls.

Manager

Price level configuration, attendant management, shift open/close, and report printing.

Technician

System configuration, serial communication settings, card reader parameters, and solenoid setup.

Calibration

W&M-controlled calibration factors. All changes logged to NTEP event log. Requires W&M inspector access.

Reports

Transaction history, shift totals, calibration event log, and system diagnostic reports.

Master

Full system access, factory default restoration, firmware version display, and diagnostic tools.

Compatible Meters

The P4 Series is factory-configured for the following meter and pulser combinations.

Neptune / Liqua-Tech

Compatible with Neptune and Liqua-Tech LPG meters equipped with the standard 250 pulser. Pulser output: 250 pulses per revolution.

Pulser Type 250

Liquid-Controls MA4 Series

Compatible with Liquid-Controls MA4 series meters without SCAMP module. Pulser output: 250 pulses per revolution.

Pulser Type 250

Liquid-Controls MA4 with SCAMP

Compatible with Liquid-Controls MA4 series meters equipped with the SCAMP temperature compensation module. Pulser output: 250 pulses per revolution.

Pulser Type 250

Mass Flow Meters

Compatible with industry-standard mass flow (Coriolis) meters for high-accuracy LPG measurement. Multiple meter types supported — contact us to confirm compatibility with your specific meter.
